# Installation

Spotlight Launcher is a [Windhawk](https://windhawk.net) **tool** mod: it runs on its own, outside File
Explorer, so it cannot affect the way Windows works.

> [!NOTE]
> Windhawk is required. The launcher is not a standalone `.exe` — it is installed, updated and configured
> from Windhawk.

## Requirements

- Windows 10 or Windows 11.
- [Windhawk](https://windhawk.net) installed.

## Install from the Windhawk store

1. Open Windhawk and go to **Mods**.
2. Search for **Spotlight Launcher** and click **Install**.
3. Press **Alt + Space** to open it.

Change the shortcut, position, effect and colours from the mod's **Settings** tab.

## Install from source

1. Download [`spotlight-launcher.wh.cpp`](https://github.com/DavidRaveloU/Spotlight-Launcher-Windhawk/blob/main/spotlight-launcher.wh.cpp).
2. In Windhawk, choose **Create a new mod**, replace the editor contents with the file and **Save**.
3. Install it from your local mods list.

## First run

- The bar appears on the monitor set by **Open on monitor** (the mouse by default).
- Type to filter your apps; **Enter** opens the one selected.
- **F1** opens the cheat sheet with every shortcut, prefix and file filter.
- Nothing needs configuring to be useful, but the [settings reference](../reference/settings.md)
  lists what can be changed.

## Upgrading

Your previous settings keep working after an update. The Settings tab is grouped by what each option
configures (Appearance, Behavior, Shortcuts, Apps, Search, Files, Clipboard, Calculator, Sounds).

> [!IMPORTANT]
> After a release that regroups options, the tab shows default values until you save it once — and
> saving applies what the tab shows. It is worth a look the first time after a big update.

## Uninstalling

Removing the mod from Windhawk also removes the folder Windhawk gives it.

> [!WARNING]
> That folder holds the clipboard images. Uninstalling deletes them, so if you want to keep something,
> copy it out first. What else the mod stores, and how to delete it, is in
> [Troubleshooting](../reference/troubleshooting.md#what-the-mod-stores).
