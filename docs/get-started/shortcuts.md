# Keyboard shortcuts

Everything is reachable without touching the mouse. **F1** (or **Help** in the footer) opens a cheat
sheet with all of this, and it scrolls when the page is longer than the bar.

> [!TIP]
> You do not need to learn these. **F1** always has the current list, including the ones added in the
> latest release — the page scrolls with the wheel or the arrow keys.

## Anywhere

| Shortcut | Action |
| --- | --- |
| **Alt + Space** | Open / close the bar (configurable) |
| **↑ / ↓** | Move the selection |
| **Tab** | Switch between apps and Files (when the file browser is on) |
| **F1** | Cheat sheet (shortcuts, prefix, filters, calculator) |
| **Enter** | Open the selected item |
| **Esc** | Close the details panel, then the bar |
| **Ctrl + Enter** | Open the location, or copy the address / item |
| **Ctrl + Shift + Enter** | Run as administrator |
| **Ctrl + Shift + C** | Copy the path |
| **Ctrl + P** | Properties |
| **Ctrl + Shift + R** | Remove from recents, or remove a clipboard entry |
| **Ctrl + I** | Details / actions panel (configurable) |
| **Ctrl + D** | Pin or unpin the selected app or clipboard entry |
| **Ctrl + R** | Rebuild the app index |
| Mouse wheel | Scroll the list without changing the selection |
| Mouse hover | Highlight the row under the cursor |

> [!WARNING]
> **Alt + Space** is also the system shortcut for a window's title-bar menu (Move, Size, Close…). While
> the mod uses it, that menu is not reachable by keyboard. If you use it, pick another combination in the
> settings.

## Files mode

| Shortcut | Action |
| --- | --- |
| **Enter** / **→** | Open the file / enter the highlighted folder |
| **←** (empty box) | Parent folder (from a drive root, the **This PC** view) |
| **Backspace** (empty box) | Up one folder (a drive root goes to **This PC**; a location root leaves Files) |
| **Alt + ← / →** | Back / forward in the folder history (mouse back/forward too) |
| **Alt + ↑** | Parent folder |
| **Alt + Home** | Home |
| **Ctrl + 1…9** / **Ctrl + ←/→** (empty box) | Jump to a location or drive chip |
| **Ctrl + Tab** / **Ctrl + Shift + Tab** | Next / previous drive |
| **Ctrl + L** / **Alt + D** | Edit the path |
| **Ctrl + Q** | Preview the file |
| **Ctrl + S** | Sort the list |
| **Ctrl + I** | Actions menu |
| **Ctrl + Enter** | Show in your default file manager |
| **Ctrl + Shift + Enter** | Run as administrator (programs) |
| **Ctrl + G** | Show the item in its own folder |
| **F2** | Rename |
| **Ctrl + Shift + N** | New folder |
| **Ctrl + T** | Open a terminal in the folder |
| **Ctrl + P** | Properties |
| **Ctrl + Shift + C** | Copy the path |

More detail: [Files](../guide/files.md).

## Windows mode (`win:`)

These keys act on the selected window and leave the bar open. **F1** lists them inside the app too.

| Shortcut | Action |
| --- | --- |
| **Enter** | Activate the window and close the bar |
| **Ctrl + I** | Panel with the actions and the window's process, state and path |
| **Ctrl + W** | Close the window (press it again to confirm) |
| **Ctrl + M** | Minimize it |
| **Ctrl + Shift + M** | Maximize, or restore |
| **Ctrl + Shift + T** | Toggle always on top |
| **Ctrl + Shift + →** / **←** | Move it to the next / previous monitor |
| **Ctrl + Enter** | Open the folder of its `.exe` |
| **Ctrl + Shift + C** | Copy the path of its `.exe` |

More detail: [Window switcher](../guide/window-switcher.md).

## Clipboard history

| Shortcut | Action |
| --- | --- |
| **Enter** | Paste the entry into the window you came from |
| **Ctrl + Enter** | Copy the entry and keep the bar open |
| **Ctrl + D** | Pin or unpin the entry |
| **Ctrl + Shift + R** | Remove the entry |

More detail: [Clipboard history](../guide/clipboard.md).
