Spotlight Launcher is a keyboard-driven launcher for Windows, packaged as a
[Windhawk](https://windhawk.net) tool mod. Press the shortcut, type a few letters, press **Enter**.

It starts with your Start menu apps, and reaches much further: files and folders, the clipboard,
browser bookmarks, Windows' recent files, open windows, a calculator, and a set of built-in commands.

> [!TIP]
> New here? [Install it](get-started/installation.md) first. Then keep [the cheat sheet](get-started/shortcuts.md)
> handy — **F1** opens the same thing inside the app, and it scrolls when the page is taller than the bar.
